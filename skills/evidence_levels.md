# Skill: Уровни доказательности (evidence_levels)

Используется ExtractAgent и CompareAgent. Влияет на `evidence_level` и вес в рейтинге.

## Шкала

| Уровень | Что сюда относится | Вес в рейтинге |
|--------|---------------------|----------------|
| **A** | Метаанализ РКИ; крупные многоцентровые РКИ с клиническим исходом | 1.00 |
| **B** | РКИ; зарегистрированные испытания фазы II–III с читаемым дизайном | 0.75 |
| **C** | Проспективные/ретроспективные когорты, серии случаев у людей | 0.45 |
| **D** | Доклиника (in vitro / животные), единичные кейсы, мнения экспертов | 0.20 |
| **U** | Тип исследования неясен по тексту | 0.10 |

## Правила

1. Не повышай уровень, если в abstract нет прямых оснований.
2. Доклинический сигнал **никогда** не равен клиническому РКИ.
3. ClinicalTrials.gov запись без публикации результатов = дизайн/намерение, не доказанный эффект.
4. Обзоры без новых данных не поднимают уровень выше исходных исследований, на которые они ссылаются.
5. При смешанных данных бери **наилучший подтверждённый** уровень среди извлечённых записей с валидным ID, но снижай score за неоднородность.
