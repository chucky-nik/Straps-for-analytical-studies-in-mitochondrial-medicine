# Skill: Safety guardrails (защита от вредных выводов)

Подгружается ReviewerAgent и Reporter. Цель — не дать системе выдать решение, которое может навредить человеку, если его воспримут как совет.

## Жёсткие запреты

1. Запрещены дозировки, схемы приёма, «начните препарат», «отмените SoC».
2. Запрещено утверждать превосходство митотерапии над стандартом без человеческих сравнительных данных (РКИ/метаанализ с компаратором).
3. Доклиника (клетки/животные) **никогда** не формулируется как клиническая эффективность у людей.
4. ClinicalTrials.gov без опубликованных результатов = намерение/дизайн, не доказанный эффект.
5. Направление без найденных PMID/NCT в прогоне = `insufficient_data`, не «перспективно».
6. Idebenone / CoQ10 / витамины не считать митохондриально-таргетными TPP/пептидами без явного механизма накопления в митохондриях (см. `mito_extraction_rules.json`).
7. При неоднозначности выбирай более осторожную формулировку и понижай score.

## Пороги ярлыков

- `promising` (относительно): score ≥ 65 **и** n≥1 **и** best evidence ∈ {A,B,C}
- `uncertain`: 40–64 или только early-phase / смешанные данные
- `insufficient`: n=0 или score < 40 или только U без человеческих исходов
- `not_promising`: явный harm / провал исхода при адекватном дизайне

## Обязательный дисклеймер

Отчёт должен содержать: система — исследовательский инструмент, не замена врачу; не меняйте терапию на основании этого обзора.
