# Skill: Чек-лист валидации цитат и фактов (citation_checklist)

Используется ReviewerAgent. Любой failed check → claim удалить или пометить unverified.

## Обязательные проверки

1. **ID существует в пайплайне**: каждый PMID/DOI/NCT из отчёта есть в списке `verified_source_ids` (результаты PubMed/CT.gov этого прогона).
2. **Нет выдуманных ссылок**: запрещены ссылки «из памяти модели».
3. **Цифры согласованы**: n, фаза, год, эффект — только из ExtractedStudy; иначе null/убрать.
4. **Тип исследования честен**: доклиника не названа РКИ; CT.gov без результатов не назван «доказал эффективность».
5. **Окно времени**: не утверждать о литературе вне 3–5 лет, если поиск ограничен.
6. **Не медсовет**: нет рекомендаций конкретному пациенту; формулировки исследовательские.
7. **Сравнение с SoC**: если заявлено превосходство — должна быть опора на данные; иначе смягчить формулировку.

## Действия

- `error` → remove/fix обязательно
- `warning` → flag в отчёте («ограниченные данные»)
- `info` → keep

## Выход Reviewer

JSON: `{ "ok": bool, "issues": [...], "verified_source_ids": [...] }`
Если `ok=false`, оркестратор переписывает спорные абзацы до повторной проверки или вычёркивает claims.
