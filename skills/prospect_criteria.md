# Skill: Критерии перспективности направления (prospect_criteria)

Используется CompareAgent для рейтинга митохондриально-таргетных направлений vs стандарт лечения.

## Формула score (0–100)

База:
- лучший evidence_level: A=40, B=30, C=18, D=8, U=4
- число независимых официальных записей (PMID/NCT) по направлению: min(n, 5) × 4
- сигнал пользы у людей (effect_direction=benefit и study_type ∈ {rct, cohort, meta_analysis} **из PubMed**, confidence≥0.45): +15
- только доклинический benefit: +5 (и потолок score ≤ 35)
- вред / провал исхода (harm): −25
- наличие сравнения со стандартом в PubMed: +8
- фаза III в ClinicalTrials.gov: +6 за дизайн (не за эффективность); registry-only потолок ≤ 45

Ограничения:
- **n=0 → score=0, label=insufficient** (не «слабая перспектива»)
- Score ≥ 65 **и** evidence ∈ {A,B,C} = `promising` (относительно, в рамках экспресс-обзора)
- 40–64 или только D/U = `uncertain`
- < 40 или n=0 = `insufficient`
- явный harm = `not_promising`

## Честное сравнение с SoC

1. Нельзя объявлять митотерапию «лучше SoC», если нет прямого human comparative сигнала.
2. SoC описывается кратко из каталога заболевания + найденных записей.
3. Если SoC имеет уровень A/B, а митонаправление только D — направление не может быть `promising`.
4. Генная терапия мтДНК (LHON) оценивается отдельно от антиоксидантов.
5. Idebenone/CoQ10/витамины не считать mito-targeted TPP/пептидами без явного механизма (см. mito_extraction_rules).

## Вывод в отчёте

Для топа и аутсайдеров обязательно: список supporting PMID/NCT, лучший уровень доказательности, label, одна фраза ограничений. Без ID — только `insufficient_data`.
